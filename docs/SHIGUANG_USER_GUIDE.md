# 快速使用

1. 安装 Releases 中的测试 APK，开启相机 Wi-Fi。
2. 在拾光输入相机显示的 SSID 和密码，允许手机弹窗和相机屏幕确认。成功后会保存本机加密连接记录。
3. 等最新一批照片出现即可浏览。按拍摄日期/类型筛选；没有日期的照片在“日期未知”。
4. 点开 JPG 后先看小图，再加载清晰版本；左右滑动切换，双击或双指缩放。RAW 以快速预览为主。
5. 选择照片，点导入原文件。通常保存为 Pictures/Shiguang、Movies/Shiguang、Download/Shiguang/RAW。
6. 导入记录按日分组。“…”菜单可打开、重试、删除或尝试用 Lab 编辑；可多选删除。
7. 删除默认只删记录，只有勾选才删除手机文件；相机卡原片不删除。正在导入的任务先取消再删除。
8. 允许扫描通知后，扫描期间可锁屏，通知提供暂停。系统强行停止后不能保证继续。

“已导入”勾选来自保留的成功记录，不是重新检查手机所有文件。删除最后一条对应记录后，勾选会消失。已有手机文件被其他 App 移走时，本地缩略图可能显示占位。

Lab 直达编辑未完成联调。如果提示没有编辑入口，打开 Lab 后从图库手动选择；不要把停在主页当作成功打开照片。

出现问题时复制“更多 → 诊断日志”中相关时间段。公开反馈前移除照片、SSID、序列号、会话令牌、challenge 参数及其他不希望公开的信息。
