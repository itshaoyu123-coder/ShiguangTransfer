# 0.2.13：EXIF 日期提前返回

## 已确认的问题
用户提供的 PANA5364.JPG 约 9.4 MB，首段 EXIF APP1 长度 51612 字节，拍摄日期字符串约在 1.3 KB。0.2.12 要求整个 APP1 段到齐后才解析，前 2 KB、8 KB、48 KB 均返回未知，约 51 KB 后才成功。

## 改动
- JPEG EXIF 段未完全收到时，也尝试解析已经完整到达的 TIFF 目录与 DateTimeOriginal 字段。
- 严格限定在已收到的数据与所属 EXIF 段内，不越界、不根据不完整字符串推测日期。
- DateTimeOriginal 尚未到达时，不提前使用已到达的修改时间代替；低优先级日期继续等待整段。
- 前缀读取步长从 8 KiB 改为 2 KiB，日期一旦取得即停止读取，仍保持 128 KiB 上限。
- 手动日期开关、逐张请求数量、相机锁与传输优先逻辑保持原样；不添加自动扫描或额外并发。
