# 0.2.14：导入目录、机型显示与轻量动效

## 保存位置
- 新 JPG：Pictures/拾光传输。
- 新视频：Movies/拾光传输。
- RAW 等：Download/拾光传输/RAW。
- Android 媒体库不可写时沿用原有应用目录回退，子目录改名为拾光传输。
- 保存实现原本已有英文 Shiguang 子目录，本版改为中文且在界面说明去向。系统相册的“所有照片”是汇总视图，分目录后仍可能显示；在相册/文件夹页查看独立相册。
- 不移动、删除或重导入旧版本已保存的手机文件，导入记录中的 URI 保持有效。

## 机型显示
右上角原先写死 S5 II，现在读取当前连接会话的机型，并规范化 DC-S9、DC-S5M2 等显示名称。未知型号显示松下相机，不默认冒充 S5 II。不新增识别请求，不改变授权流程。

## UI 与动画
- 保留米白与深绿色，筛选选中态统一为深绿。
- 标题切换淡入和小幅位移；选择操作条轻量进出。
- 选中照片增加轻微弹性缩放和边框反馈；缩略图短淡入。
- 确定的扫描进度平滑变化。
- 不交叉渲染两个胶卷列表、不增加取图请求或动画循环。交互流畅度与系统动画策略需真机确认。

## GPS 评估：本版不实现
给手机已导入 JPEG 写坐标在技术上可做，但导入地点不是拍摄地点，不应自动混淆。
若要准确记录拍摄位置，需要拍摄期间记录位置轨迹并按相机时间匹配，或适配相机定位同步通信；需要权限、时间同步、后台耗电和跨机型验证，不符合当前优先保证导入体验的阶段。
Android 官方参考：
https://developer.android.com/reference/androidx/exifinterface/media/ExifInterface
https://developer.android.com/develop/sensors-and-location/location/permissions
