# 0.2.2 预览与界面修正

本版包含 FIX_0.2.1_SOAP701.md 的通信恢复修正，尚需 S5 II 真机验证。

- 打开照片先显示内存中的快速预览；没有缓存时只请求相机缩略图。不会自动读取 11 MB 等大小的 JPG 原文件。
- JPG 可点“读取原图”请求原文件并解码到最长边约 2048 像素。该操作不是保存到相册；“导入原文件”仍独立下载完整文件。
- 快速预览最长边约 420 像素，放大仍可能模糊。没有宣称相机提供高清预览。
- JPG/RAW 共用相同预览 URL 时复用缓存；最多缓存 96 个预览资源、2 张已读取的原图预览。仅进程内缓存。
- 预览改为 Activity 内的独立页面，使用 safeDrawing 系统安全区；底部操作不再采用全屏 Dialog 的固定布局。
- 图片存在时使用顶部进度条，不再在图片中央覆盖转圈。原图显示已读取字节。
- 双击与双指缩放；照片保持原比例完整展示，因此横图在竖屏上仍有合理留白。
- 返回胶卷保留滚动位置。加载结束后允许后台目录扫描继续。

## 真机复测

1. 覆盖安装后，点已出现缩略图的 JPG：应立即显示，且不自动出现 11 MB 原图读取。
2. 点“读取原图”：观察顶部字节数及清晰度变化。返回再打开同图，应复用内存缓存。
3. 测试 JPG+RAW、只有 RAW 的照片；预览内容应与原文件对应。
4. 小米 15 手势导航下检查底部两个按钮完整显示；再测试三键导航、大字号、横屏。
5. 双击/双指缩放后返回，检查胶卷滚动位置及扫描继续。
6. 连接失败时刷新，核对 SOAP 701 是否恢复；若仍失败导出诊断。
