# 0.2.16：按速度加载与当前位置日期优先

## 滚动策略
仅在前台胶卷页以约 50 ms 间隔采样行位置，按当前行高折算“行/秒”，不是固定像素阈值。
- 低于 1 行/秒：允许可见照片的新缩略图请求。
- 1～3 行/秒：保留已有任务，不启动新的任务。
- 高于 3 行/秒持续约 100 ms：暂停并取消在途缩略图任务。
- 低速或停止持续约 150 ms 才恢复，避免阈值附近反复取消/启动。
- 缓存中的图一直可见，点开详细预览沿用独立的优先请求；不增加网络并发或相邻图片预取。
- 采样不在后台、导入历史页或详细预览期间循环。阈值是第一轮可调值，需要手机实测跟手程度。

## 手动日期任务
独立补日期仍需手动开启。任务范围仍为开启时已扫描的候选照片快照；不自动追加新扫描照片。
- 当前可见照片优先，其次是原始胶卷顺序中距离当前视口最近的照片。
- 每次真正取得相机访问锁后，按最新视口重选下一张，避免从卡首一路补到用户当前位置。
- JPG/RAW 继续共用照片资源身份，已从预览或导入取得日期的候选不再请求。
- 滚动期间不启动下一次日期请求；预览与导入优先。已开始的一次响应不保证立即被抢占，保持现有超时和取消机制。
- 无可用视口时回退到原有顺序；换卡/刷新/断开沿用任务取消和会话检查。

这不是日期接口提速，不承诺每秒处理张数增加，也不会立刻提供全卡日期筛选。位置附近的日期应更早可用。跨连接持久化日期缓存仍暂缓，没有新增相机/存储卡身份推测。
