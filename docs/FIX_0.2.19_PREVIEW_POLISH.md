# 0.2.19 体验打磨

本轮在 0.2.18 基础上改善手机端浏览反馈，不改动相机通信、目录扫描、下载调度、日期读取或后台扫描服务。

## 改动

- 详细预览中，同一张照片从已有缩略图切换到清晰图时采用 160ms 淡入；过渡由照片路径隔离，不把上一张照片淡入下一张。不主动预取相邻原图。
- 预览失败时显示「重试预览」，仅由用户点击后执行；复用原有请求、取消、相机会话及传输优先逻辑。
- 将导入记录列表状态提升到主页，避免页面离开组合后重新进入时丢失滚动位置。相机胶卷已有独立网格状态，继续保留。
- 下载状态区分准备导入、正在接收及速度为零时的等待响应；未知文件大小使用不定进度，已知进度限制在有效范围。

## 回归与限制

Release 构建通过；Transport 48 项测试、协议访问调度/预览访问/连接取消 12 项针对性测试通过。Lint 0 错误、50 警告。APK 签名与 0.2.18 一致，versionCode 22。未运行存在已知上游失败的协议完整测试集。未连接 Android 真机，动画观感、前后台切换和真实相机速度仍需实测。等待响应提示依据现有下载字节数与速度，不是新增的网络状态探测。

## 建议体验

1. 点击已有缩略图的 JPG，观察清晰替换；左右切图、返回后应仍在原胶卷位置。
2. 导入记录滚动到中间，切到胶卷再切回，检查位置。
3. 预览遇到失败时点击重试；有下载进行时仍应遵循下载优先。
4. 导入一组 JPG/RAW，确认保存路径和完成结果与之前一致。
