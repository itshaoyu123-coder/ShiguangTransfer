# 0.2.25 氛围背景、外观设置与动效

## 产品方向与基线
以用户认可的海岸晨雾概念图和0.2.20布局为基础，撤回0.2.24紧凑蓝紫工具风。新增截图仅作视觉参考：温暖底色、大圆角、留白与文字层级，不复制其品牌、图像或LUT/AI功能。

相机通信继续采用0.2.20行为；没有带回0.2.23预览自动会话恢复或0.2.22日期等待窗口。未声称旧连接/预览故障已解决。保留原后台诊断、缓存/预览/传输/手动日期调度。

## 界面
- 主界面为大范围柔和纵向渐变，叠加一次缓存的静态径向色层，营造雾青到暖米色的自然晕染；不采样照片、不实时模糊、不持续动画。
- 沿用原SHIGUANG/拾光标题、胶卷/导入记录、三列照片与滑动分页。
- 相机状态胶囊、筛选按钮、导入记录卡片为半透明浅色表面；底部已选/导入操作区改为留边圆角浮层，白色主操作按钮。
- 详细预览继续暗底，照片不覆盖渐变、不改变缩放/读取逻辑。

## 外观与背景
入口：右上角更多→外观与背景。
四组预设：海岸晨雾（默认）、云间蓝调、暖砂日光、林间微光。点选预设即时应用。
自定义支持顶部/中间/底部三色：可点选柔和色块，也可输入六位#RRGGBB，预览后点击应用。非法/八位含透明度输入不会应用。提供一键恢复默认。
只保存在本机独立SharedPreferences；重启后读回。Compose主题通过监听偏好更新，不重建相机会话、不重新扫描相机。
自定义深色自动柔化至亮度下限，保持主要及辅助文字可读；因此最终呈现可能比输入色更浅，界面明确说明。原始色值仍保存，便于继续修改。

## 版本显示修复
旧更多窗口写死0.2.18，已移除。改为读取宿主包名的PackageInfo版本名和longVersionCode；本包显示0.2.25-alpha (29)，以后随实际安装包更新，不从transport模块常量推断。

## 轻量非线性动效
统一使用缓出曲线CubicBezier(.22,1,.36,1)和低回弹弹簧：页面标题、底部导入栏、选择缩放和清晰替换；点选主页标签以临界阻尼弹簧滚动。保留跟手分页、预览左右滑动和系统返回边缘，不引入新请求或预取。沿用Compose系统动画时长缩放机制。

## 验证与限制
新增UI单元测试：颜色输入合法性、存储文本往返、自定义深色/预设辅助文字对比度。初版色彩混合未达对比度要求，已改为按实际亮度柔化，重新通过。
未连接真机，本机模拟器仍无可用运行环境；不能宣称已完成实际截图、字体缩放、动画观感或偏好重启的设备验证。生成概念图仅为视觉参考，不是APK运行截图，示意照片不会作为App素材加入。
