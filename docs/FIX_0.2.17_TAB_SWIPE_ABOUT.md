# 0.2.17：中部滑动切换与产品简介

## 改动
- 普通“关于”页改为拾光的产品简介，不再出现“基于你提供的……代码改进”等聊天式开发说明。
- “开源声明”入口、OPEN_SOURCE_NOTICES、源文件署名和许可证保持原样；本次不是删除项目来源记录。
- 相机胶卷内容区左滑进入导入记录，导入记录右滑回胶卷；点击原有两个标签仍有效。
- 起点位于两侧保留区域的手势不接管。保留范围取系统手势左右边距与 32 dp 中的最大值，不设置系统手势排除区。
- 越过系统水平触摸阈值后才跟踪，至少横移 64 dp 且横向距离大于纵向的 1.3 倍才切页；竖向滚动不主动接管。
- 使用当前页面的 220 ms 短位移/淡入，不同时组合或预加载两套胶卷，不改变网格滚动位置的存储方式。
- 详细预览保持原有照片翻页手势，切页手势仅安装在主页内容区域。

## 核心功能范围
没有修改连接管理、授权、下载器、日期补全或缩略图调度逻辑。本版仅新增主页手势和过渡、替换关于文案及版本号。

## 验证边界
新增切页方向、短拖动和主要竖向拖动的策略测试，配合传输模块回归、Release 编译和 lint。边缘返回、长按选片、列表竖向滑动与动画实际表现需真机验证，没有宣称达到系统级跟手动画。
