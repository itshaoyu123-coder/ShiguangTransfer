# 0.2.26 胶卷细节与照片方向

用户已认可0.2.25外观，要求保留当前背景与原图标，只做有限细节改善。通信与调度继续以0.2.20行为为基线，不带回日期等待或预览自动会话恢复实验。

## 标签胶囊
旧胶卷TextButton只设置了右侧18dp内容边距，按压态胶囊相对于文字偏向一侧。胶卷和导入记录现统一为左右16dp、上下8dp、至少48dp点击高度和CircleShape。沿用原按钮反馈和分页，不新增阴影或位移动画。

## 名称
去掉相机型号两端的英文/中文引号和空白，再做原有型号映射。连接胶囊显示LUMIX S5 II等规范名称；未识别机型仍显示松下相机，不猜型号，不混淆S5/S9/S5 II。仅显示层清理，不修改会话识别或通信内容。

## 日期
胶卷缩略图下方只在已知日期时显示日期；未知时保留文件名，不重复显示日期未知。日期筛选及详细预览中的未知状态继续保留，不自动开启日期任务。缩略图列数、图像比例和请求调度不变；屏幕可见照片数量可能因文字行减少略有增加。

## 方向
发现原decodePreview使用BitmapFactory但未应用EXIF方向。现在从已取得的预览/JPG字节读取TAG_ORIENTATION，对采样后显示位图处理EXIF2–8（含旋转及镜像），普通/缺失/非法方向不处理。变换失败保留已解码图像，不导致整张预览消失。
对胶卷快速缩略图和清晰预览使用相同路径，先处理方向再缓存；不读取额外原图、不修改相机原片/已保存手机文件。不根据宽高或拍摄对象猜方向。相机若剥离缩略图EXIF，不能保证该快速图自动纠正；需真机核实。原图导入仍保存原文件及原EXIF。

## 验证
新增型号引号处理回归、方向旋转/镜像角点次序及正常/非法标记回归；继续跑外观色彩、Transport和协议访问门/预览/取消针对性测试、Release与Lint。
本机没有可用运行模拟器或相机，胶囊实际按压观感及具体相机照片方向尚待真机体验，不能宣称已验证截图中每张照片都已纠正。
