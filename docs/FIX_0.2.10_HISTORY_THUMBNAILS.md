# 0.2.10 导入记录本地缩略图

- 导入记录左侧加入 56dp 方形缩略图，多选模式下保留复选框和缩略图。
- 仅 COMPLETED 且具有 content:// 或 file:// 手机地址的记录参与；不读取正在写入、排队或失败任务的文件，不接受相机 HTTP 地址作为缩略图来源。
- 优先 ContentResolver.loadThumbnail，失败后尝试 ImageDecoder 按小尺寸解码本地图片；RAW 或视频能否显示取决于系统提供者/解码支持，不能读取时显示格式占位图。
- 解码在 IO 线程，最多两个并发任务，最长边 192 像素；缓存按 URI 和完成版本区分，上限约 6MB，退出记录页时清理。
- LazyColumn 按需生成（含系统少量布局预取），不遍历解码整个历史。离开条目时取消请求，系统缩略图使用 CancellationSignal。
- 没有新增相机请求或修改正式下载流程。仍有少量本地读取/解码成本，本机没有真机速度对比，不宣称绝对零开销。
- 已有打开、删除、按日分组、Lab、胶卷已导入标记、扫描/锁屏策略保持。

## 真机复测

1. 打开导入记录，之前保存的 JPG 应出现缩略图，照片方向与内容正确。
2. 滚动较长历史，检查按需加载、返回记录页和内存表现；不应发出额外相机图片请求。
3. 导入进行中显示占位，完成后自动切换到本地缩略图，不读部分文件。
4. 测试本地 RAW、视频、文件被移走/删除和缺少读取权限时的占位；记录操作仍可使用。
5. 选择、删除手机文件或仅删除记录，检查缩略图没有串到其他记录。

本机没有真机或可运行的模拟器，未验证实际缩略图、RAW 支持和导入速度。
