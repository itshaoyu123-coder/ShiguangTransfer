# 0.2.8 预览分页动画、拍摄日期与 Lab 编辑入口

## 预览动画

- 使用 Compose HorizontalPager 实际分页拖动、吸附与动画，替代到达阈值后直接替换照片。
- 松手停到新页后才调用清晰预览读取，不为滑过的每一页下载原图。邻页先显示已有缩略图。
- 前后按钮调用 animateScrollToPage；首尾不循环。1 倍时滑动切图，放大后拖动查看图片。
- 保持当前分类队列快照、原有缓存、扫描和后台保护。

## 拍摄日期

- 胶卷每张缩略图下显示 yyyy-MM-dd；新增“拍摄日期”入口，按日筛选、全部日期和日期未知。
- 日期选项按日从新到旧，统计当前文件类型中已扫描的文件；JPG/RAW 等类型筛选与日期组合。
- 优先相机 DIDL 的拍摄日期，其次已读取 EXIF；同一相机资源的 JPG/RAW 可共用对应 EXIF 日期。
- 增补带时区 ISO、无时区 ISO、本地 EXIF 风格及秒/毫秒时间戳解析。无时区日期按手机时区解释，取决于相机时钟是否设置正确。
- 不再将预览 HTTP Last-Modified 作为拍摄时间来源。不用手机导入时间代替，不为筛日期额外下载原图。
- 日期缺失的照片明确列为未知。未知日期不自动归入某个日期；扫描尚未结束时筛选范围仍随已读元数据扩展。

## 真机复测

1. 左右拖动应能看到相邻页移动、松手吸附；箭头有过渡动画。快速滑过多张后只停留页加载清晰图。
2. 放大后拖动不切页，缩回 1 倍后再切；核对页码、文件名、照片对应。
3. 检查已知拍摄日期是否与相机一致；选择某日后 JPG/RAW 各分类数量是否合理；日期未知和全部日期可恢复列表。
4. 筛日期期间锁屏后重新进入，检查扫描继续且不额外读取整张 JPG。
5. 单张手机 JPG 点“用 LUMIX Lab 编辑”，若仍无编辑页，复制 lab-handoff 日志，或提供正在使用的 Lab APK 继续分析；不要把手动打开主页当作直达功能已完成。

没有真机 UI、日期元数据和 Lab 编辑交付验证。本版只交付已实现的分页/筛选与编辑入口探测，不宣称第三项已实现。
