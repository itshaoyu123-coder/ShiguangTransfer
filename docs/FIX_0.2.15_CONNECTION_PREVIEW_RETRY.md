# 0.2.15：连接阶段、预览调度与下载重试

## 本次实现
1. 胶卷访问状态与网络连接分开：待授权、授权中、读取胶卷、访问未完成；取得目录结果后才显示已连接。相机网络可达的诊断不再称为握手成功，网络等待超时也写入日志。
2. 快速滚动时取消在途缩略图任务并暂停新任务，停下后按当前可见条目请求。缓存仍可直接显示。切换 JPG/RAW 等分类时立即关闭旧预览并取消旧缩略图任务，已有连接取消机制负责释放请求。
3. 下载沿用断点续传、Range 验证、长度/结构检查和有限重试。新增重试分类：超时、5xx、408/429 以及需重新起步的 416 最多两次；明确的其他 HTTP 失败和存储空间不足不自动重复。重试前核对相机会话，防止在重连后的新协议会话上继续旧文件重试。
