# 0.2.18：跟手分页与后台扫描生命周期

## 跟手分页
主页内容区改用 Compose HorizontalPager；拖动直接移动页面，松手后吸附，点击标签也滚动到对应页。保留两侧系统手势范围与至少 32 dp 保护区，不使用系统手势排除。
原 0.2.17 的松手判定/短位移实现和对应策略测试已移除。详细照片预览继续使用独立分页，不与主页抢手势。
横向切换期间不请求胶卷缩略图，非当前胶卷页释放其在途请求。相邻页面可以为跟手效果参与布局，但没有两套相机胶卷或额外相机并发。
官方组件说明：https://developer.android.com/develop/ui/compose/layouts/pager

## 后台扫描
用户反馈：扫描通知仍在，但后台进度不动。这说明不能把原因简单认定为服务没启动。
修正已发现的生命周期风险：
- 移除服务销毁时无条件暂停扫描的副作用，避免旧服务停止影响新扫描。
- 对短暂空闲状态延迟一秒停服；新的活动状态会取消旧停服等待，并使用最新 startId。
- App 退后台前补查前台服务保护；保留 CPU/Wi-Fi 锁和相机会话保活。
- 用户主动暂停和系统服务超时仍会停止扫描，未绕过系统限制。
- 增加服务启动、销毁、通知是否可见、App 退后台时的扫描状态日志；每 15 秒记录健康状态，30 秒以上无进展记录扫描任务、暂停/预览状态和相机锁等待情况。

本次没有盲目重置相机锁或定时取消/重试整轮扫描。仍需根据真机新日志区分相机响应阻塞、访问锁等待、网络丢失与系统后台限制，不能宣称该用户的后台停滞已完全定位或彻底解决。
Android 服务限制参考：https://developer.android.com/develop/background-work/services/fgs/timeout

## 验证
运行相机锁、连接取消定向测试与传输模块回归、Release 编译、lint、签名校验。没有实际 Android 设备进行后台/锁屏、边缘返回和跟手帧率验证。
