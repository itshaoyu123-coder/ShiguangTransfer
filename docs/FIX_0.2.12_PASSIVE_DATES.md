# 0.2.12：不额外请求相机的日期收集

## 范围
保留手动“补全拍摄日期”。没有添加自动逐张读取日期的相机请求。

- 目录已有日期继续直接使用。
- 已读取的缩略图和清晰预览继续提取 EXIF；清晰图即使不能解码成位图，也能独立保留可解析的日期。
- 当前相机会话中新建的导入任务完成后，等待传输队列空闲，再从手机上的完成文件读取最多 128 KiB 日期元数据。处理在 IO 线程，读取到日期即提前结束，不重新下载文件、不调用相机授权/目录接口。
- 仅通过本次会话创建的任务 ID 关联图库，断开后清空绑定；检查读取前后的相机会话及扫描代次，避免旧导入记录按同名路径污染当前图库。
- 视频不读取；已知日期不重复处理；读取失败不改变成功的传输状态。

## 暂缓
没有实现跨连接的远程文件日期缓存。协议模型虽可能包含相机序列号，目前没有可靠的存储卡身份和文件版本标识，不能靠 SSID、IP、文件名、大小来保证换卡后不串日期。

日期仍只在当前图库会话保留。旧导入记录、App 重启后或已断开相机的完成任务不会自动回填到新相机图库。这是当前实现范围，不宣称持久化日期缓存已完成。

## 验证与实际边界
本地文件的前缀解析复用 0.2.11 的 JPEG/TIFF/RW2 解析器与读取上限。运行协议定向测试及传输模块测试、Release 编译和 lint；没有真机验证任务完成后的日期回填和队列切换。

此次没有更改下载器、相机锁或队列调度算法。新增本地读取及状态更新仍有少量 CPU/磁盘成本，不承诺所有设备上绝对零性能影响。
