# 0.2.11：补全相机照片拍摄日期

## 问题
0.2.10 日期筛选只使用 UPnP 目录日期和已读取预览的 EXIF。相机目录不带日期、快速缩略图也没有 EXIF 时，整个列表可能显示未知。缓存缩略图直接回显时也没有把缓存中的日期回填到筛选状态。

## 改动
- 修正缩略图缓存命中时的日期回填。
- 日期筛选面板新增“补全拍摄日期”和暂停、进度提示，手动读取当前已扫描照片的元数据。
- 请求原片 bytes=0-131071，最多消费 128 KiB，读到完整日期后提前停止。相机忽略 Range 返回 200 时仍保持读取上限，不下载完整原片来获取日期。
- 从 JPEG APP1 / TIFF / RW2 文件头解析 DateTimeOriginal，支持大小端；严格检查长度和指针边界。
- RAW+JPG 共享日期，优先读取 JPG；排除视频和已知日期，避免同照片重复请求。
- 复用相机访问锁、只在连接空闲且没有详细预览时执行；导入和预览优先，逐张让出连接。显式 403 时沿用现有一次授权恢复。
- 不自动增加普通胶卷浏览的元数据请求，不使用 HTTP 日期、文件名或导入时间推测拍摄日期。

## 使用
打开日期筛选，点击“补全拍摄日期”。日期逐渐出现后即可筛选。可随时暂停，当前会话保留已获取日期。新扫描出来的照片需要再次点击补全；断开、刷新或切换相机会停止本次日期读取。

## 边界
本功能增加手动元数据请求，大卡可能需要较长时间。元数据超出读取上限、文件没有日期、视频或不支持的格式仍会显示未知。日期目前保留于当前会话，不是持久化全卡索引。EXIF 未含时区时沿用手机本地时区。需要 S5 II 真机确认，不宣称已解决所有日期缺失。

## 验证
协议定向测试 17 项、传输模块测试 38 项通过（共 55 项）；本次并未运行完整上游协议测试。覆盖 JPEG/TIFF/RW2、大小端、截断/越界、读取上限、提前停止、Range 授权重试、RAW/JPG 去重和已有日期跳过。
