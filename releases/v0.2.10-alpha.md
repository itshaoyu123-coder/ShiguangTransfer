# 拾光传输 0.2.10-alpha

首个准备公开到 GitHub 的源码快照与测试安装包，主要面向 Panasonic S5 II（S5M2）试用。

## 包含什么

- 最新窗口优先、渐进扫描与可见缩略图；JPG 点开后再加载清晰版本。
- 预览滑动、缩放、拍摄日期筛选与“已导入”标记。
- 带进度通知的后台扫描保护；同会话继续扫描与错误恢复。
- 按日导入历史、多选、手机文件删除选项，以及本地历史缩略图。
- 0.2.10 本次新增的是导入记录本地缩略图；不增加相机取图请求。

## 已知边界

- Alpha 测试版，其他机型/固件未系统验证。
- LUMIX Lab 直达编辑尚未完成；不能把进入 Lab 主页当作成功打开所选照片。
- RAW 缩略图、日期缺失、系统后台策略及全卡回归仍需真机验证。
- 当前使用测试签名；CI 自编译 APK 不保证可覆盖此安装包。
- 仅删除手机文件或本地导入记录，不删除相机卡原片。

0.2.10 本次 transport 37 项测试通过，Release 编译与签名校验通过，lint 为 0 errors / 70 warnings。完整输入协议测试保留 4 项已知失败；未完成真机自动化验证。
