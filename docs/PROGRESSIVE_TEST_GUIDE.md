# LumaLink 渐进版3测试说明

第三版新增后台短暂错误原页重试和单条扫描暂停提示，优先使用设备公布的服务地址。第二版特别修复：不再把 get_content_info 的文件数当作 UPnP 对象分页下标。界面分别显示文件数与对象扫描进度。

基于 Angelnable/LumaLink 4.3.11（main 24a0156）修改的个人测试版，不是作者的官方新版。

## 安装与连接

应用名：LumaLink 渐进版3。包名：com.lumalink.g100d.progressive2。可直接覆盖第二版；与官方原版独立安装。首次安装此包需重新授权。
连接前退出原版、LUMIX Sync 和 LUMIX LAB，避免同时操作相机。通过相机 Wi-Fi 连接测试版。

## 本次修改

- 获取总数后优先请求末尾 50 项，按相机页内顺序倒序显示；后台继续读更早的页。
- 每一批读取后立刻显示；已有照片可预览、勾选、下载，不必等待全卡扫描。
- 当前可见缩略图优先于后台扫描；查看大图或传输时暂停后续扫描。
- 使用相机提供的原文件名和缩略图 URL，缓存已确认无效的控制地址。
- 保留已读列表与选择；刷新/断开连接时取消旧扫描，拒绝过期回调。
- 短页继续补读；读取失败保留可用照片并明确提示未完成。
- 若相机不返回总数，回退到带提示的渐进正向读取，不能保证最新优先。

## S5 II 实测清单

1. 插入照片最多的卡，确认首批是否包含相机上最后拍摄的照片，顺序是否正确。
2. 无需等待扫描结束，点开首屏大图，再关闭，确认扫描继续。
3. 扫描期间勾选几张，等待下一批后确认选择仍保留。
4. 下载一张照片，确认原图可打开；留在文件页，确认下载结束后缩略图继续加载。
5. 快速滚动，确认离屏请求不长期阻塞当前屏幕；切换 JPG/RAW 筛选检查显示。
6. 点击刷新，或断开后换卡重连，确认旧卡照片不会重新出现。
7. 对比相机显示的总数和最终加载数。相机的逻辑项目数可能与 RAW+JPEG 资源数不同。

第二版已收到 S5 II 预览与下载可用的反馈；第三版仍待真机验证。协议模拟测试和成功编译不能保证所有相机固件的分页、授权和尾页行为一致。失败时复制诊断日志中的 upnp-newest、transfer-access 和错误行。

## 源码构建

JDK 17、Android SDK 35、Build Tools 35.0.0、Gradle 8.9。运行 `./gradlew :app:assembleDebug`。
协议新增测试：`./gradlew :protocol:test --tests '*ProgressiveBrowseTest' --tests '*CameraAccessGateTest'`。
